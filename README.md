# GitHub Repository Standards

This repository defines the standard configuration and engineering controls
for GitHub repositories.

## Purpose

The objective is to provide a consistent baseline for:

- Repository structure
- CODEOWNERS
- GitHub Actions
- Security scanning
- Infrastructure validation
- Branch protection
- Repository metadata
- Repository governance

## Standards

Repositories created from this standard should include:

- CODEOWNERS
- Standard GitHub Actions workflows
- Pull request standards
- Security checks
- Required repository topics
- Protected default branch
